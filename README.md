# YPod 0.3

MP3 player offline para Samsung Galaxy Y Duos GT-S6102B, Android 2.3.6 (API 10).

## Como baixar o APK

Acesse **Actions → Build YPod APK**. Após uma compilação bem-sucedida, abra a execução e baixe o artefato **YPod-APK**. Extraia o ZIP e copie o arquivo `.apk` para um cartão microSD. Instale no celular com **Fontes desconhecidas** habilitadas.

Esta é uma versão inicial não testada no aparelho: lista músicas catalogadas pelo Android, toca MP3, pausa e avança/retrocede. Não substitui o Android e não depende de conta Google.

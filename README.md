# YPod OS 2.0 — Edição Personalizada

Interface retrô inspirada nos tocadores de música clássicos, adaptada ao Samsung Galaxy Y Duos GT-S6102B (Android 2.3.6 / API 10).

## Novidades

- Tela inicial com seis atalhos em grade, dock com efeito de vidro e paleta roxa.
- Biblioteca de músicas locais, artistas, álbuns e playlists.
- Player offline com controles de reprodução e progresso.
- Tela de ajustes e confirmação para sair do aplicativo.

## Instalação

Acesse **Actions → Build YPod APK** após integrar esta branch à main. Abra uma execução bem-sucedida e baixe o artefato APK. Transfira-o para o cartão SD e instale no aparelho com **Fontes desconhecidas** habilitadas.

> O redesign ainda não foi validado em hardware real. Este app não substitui o firmware Android. A arte conceitual é uma referência de estilo, não uma representação exata das telas implementadas.

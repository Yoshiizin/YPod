Quando houver capturas reais:
1. Faça screenshots/fotos com a interface rodando no Galaxy Y.
2. Remova dados privados ou notificações.
3. Informe o nome, versão e dispositivo na legenda.
4. Salve em `docs/screenshots/` e atualize o README.
